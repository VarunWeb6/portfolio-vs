## 1. Pre-Flight Checklist

Before writing a single line of code, answer these questions:

```
WHO is the audience?        → B2B enterprise / consumer / creative / developer / luxury?
WHAT is the core emotion?   → Trust / excitement / calm / urgency / delight / power?
WHAT era/mood?              → Retro-futurism / Swiss minimalism / Neo-brutalism / Organic / Editorial?
WHAT is the ONE thing       → The single visual moment someone will screenshot and share?
someone will remember?
WHAT is the tech stack?     → Next.js + Tailwind? Astro? Plain HTML? React + Framer Motion?
```

**CRITICAL**: Commit to a BOLD aesthetic direction. Mediocre design comes from trying to please everyone. Great design comes from a strong point of view executed with precision.

## 2. Design Philosophy

### The 5 Pillars of Non-Generic Design

#### Pillar 1: Intentional Contrast
Every page needs ONE dominant visual tension:
- Large vs. small typography
- Dense content vs. vast whitespace  
- Geometric precision vs. organic shapes
- Monochrome vs. a single explosive accent
- Static elements vs. one dramatic animation

#### Pillar 2: Contextual Character
A fintech dashboard should NOT look like a portfolio site. A children's app should NOT look like a SaaS landing page. Design decisions must emerge from the product's identity:

| Context | Mood | Typography | Color | Layout |
|---------|------|-----------|-------|--------|
| Fintech SaaS | Trustworthy, precise | Mono + geometric sans | Dark + green/blue accents | Grid-locked, data-dense |
| Creative Portfolio | Expressive, bold | Display serif + experimental | High contrast, unexpected | Asymmetric, overlapping |
| E-commerce Luxury | Refined, aspirational | Thin serif + wide tracking | Black/cream/gold | Generous whitespace |
| Dev Tools | Technical, efficient | Monospace + clean sans | Dark mode, neon accents | Compact, information-rich |
| Health/Wellness | Calm, organic | Rounded sans + soft serif | Earth tones, pastels | Flowing, breathable |
| AI/ML Product | Futuristic, intelligent | Geometric sans + mono | Dark + gradient accents | Clean with subtle depth |

#### Pillar 3: The "Screenshot Test"
Before shipping, ask: "Would someone screenshot this and post it on Twitter/X saying 'look at this beautiful site'?" If no → iterate.

#### Pillar 4: Restraint is a Superpower
More effects ≠ better design. A minimalist site with perfect typography, spacing, and one subtle animation will ALWAYS beat a site with 47 gradients, 12 animations, and 6 fonts.

#### Pillar 5: Sweat the Details
The difference between good and great is in the micro-details:
- Border radius consistency across ALL elements
- Consistent spacing rhythm (use a base unit: 4px, 8px, etc.)
- Hover states on every interactive element
- Smooth transitions on color/opacity/transform changes
- Text rendering optimization (antialiasing, kerning)
- Scroll behavior (smooth, with appropriate offsets)
- Focus states for accessibility
- Loading states that feel designed, not default

## 3. Typography System

### The Rules

1. **NEVER use**: Inter, Roboto, Arial, Helvetica, system-ui as your primary font. These are the hallmark of AI-generated sites.
2. **ALWAYS pair** a display/heading font with a body font. Never use one font for everything.
3. **Font size scale** should be dramatic. Headings should be 3-6x larger than body text. Timid sizing = boring.
4. **Letter-spacing** is a secret weapon. Wide tracking on uppercase small text. Tight tracking on large headings.
5. **Line-height** for body text: 1.5-1.7. For large headings: 0.9-1.1 (tight!).
6. **Font-weight contrast**: Use the extremes. 300 + 800. Not 400 + 500.

### Recommended Font Pairings (Google Fonts)

Pick ONE pairing per project. Never reuse across projects.

**Editorial / Magazine**
```css
--font-display: 'Playfair Display', serif;
--font-body: 'Source Sans 3', sans-serif;
```

**Neo-Brutalist / Bold**
```css
--font-display: 'Unbounded', sans-serif;
--font-body: 'IBM Plex Mono', monospace;
```

**Luxury / Refined**
```css
--font-display: 'Cormorant Garamond', serif;
--font-body: 'Outfit', sans-serif;
```

**Tech / Modern**
```css
--font-display: 'Syne', sans-serif;
--font-body: 'General Sans', sans-serif; /* or 'Satoshi' via fontshare.com */
```

**Playful / Friendly**
```css
--font-display: 'Bricolage Grotesque', sans-serif;
--font-body: 'DM Sans', sans-serif;
```

**Swiss / Minimal**
```css
--font-display: 'Instrument Serif', serif;
--font-body: 'Instrument Sans', sans-serif;
```

**Geometric / Futuristic**
```css
--font-display: 'Clash Display', sans-serif; /* fontshare.com */
--font-body: 'JetBrains Mono', monospace;
```

**Warm / Organic**

## 4. Color & Theming

### The Rules

1. **NEVER use** purple-gradient-on-white. It's the #1 AI slop indicator.
2. **Commit to a palette**: 1 dominant, 1 accent, 2-3 neutrals. That's it.
3. **Dark mode first** often produces more striking results. But if going light, make it WARM (cream, not pure white).
4. **Background is never just a flat color**: Use subtle gradients, noise, grain, or texture.
5. **Define ALL colors as CSS custom properties** for easy theming.

### Color System Template

```css
:root {
  /* Surface colors */
  --bg-primary:    #0a0a0b;        /* Main background */
  --bg-secondary:  #141416;        /* Cards, sections */
  --bg-tertiary:   #1c1c20;        /* Elevated elements */
  --bg-glass:      rgba(255,255,255,0.03); /* Glassmorphism */

  /* Text colors */
  --text-primary:   #f5f5f7;       /* Main text */
  --text-secondary: #8e8e93;       /* Subdued text */
  --text-tertiary:  #48484a;       /* Muted text */

  /* Accent — pick ONE bold accent */
  --accent:         #00ff87;        /* Primary accent */
  --accent-muted:   #00ff8720;     /* Accent at 12% opacity */
  --accent-subtle:  #00ff870a;     /* Accent at 4% opacity */

  /* Borders & Dividers */
  --border:         rgba(255,255,255,0.06);
  --border-hover:   rgba(255,255,255,0.12);

  /* Shadows */
  --shadow-sm:  0 1px 2px rgba(0,0,0,0.3);
  --shadow-md:  0 4px 12px rgba(0,0,0,0.4);
  --shadow-lg:  0 12px 40px rgba(0,0,0,0.5);
  --shadow-glow: 0 0 40px var(--accent-muted);
```

## 5. Layout & Spatial Composition

### The Rules

1. **Break the grid** — at least once per page. One element that overlaps, bleeds, or defies the column structure.
2. **Asymmetry > Symmetry** for hero sections. Center-aligned everything = boring.
3. **Section rhythm**: Alternate between dense and sparse sections. Never have two dense sections back-to-back.
4. **Viewport-height sections**: Heroes should be at least 90vh. Let sections breathe.
5. **Max-width for readability**: Body text lines should be 60-75 characters max.

### Spacing System

```css
:root {
  --space-1:  0.25rem;   /* 4px */
  --space-2:  0.5rem;    /* 8px */
  --space-3:  0.75rem;   /* 12px */
  --space-4:  1rem;      /* 16px */
  --space-5:  1.5rem;    /* 24px */
  --space-6:  2rem;      /* 32px */
  --space-7:  3rem;      /* 48px */
  --space-8:  4rem;      /* 64px */
  --space-9:  6rem;      /* 96px */
  --space-10: 8rem;      /* 128px */
  --space-11: 12rem;     /* 192px */
  --space-12: 16rem;     /* 256px */
}
```

### Layout Patterns That Stand Out

**The Offset Grid** — Content doesn't start at the same Y position
```
┌──────────────────────────────┐
│  HEADING          ┌────────┐ │
│  LARGE            │ IMAGE  │ │
│  TEXT              │ OFFSET │ │
│                   │ DOWN   │ │
│  subtext          └────────┘ │
└──────────────────────────────┘
```

**The Overlap** — Elements break their containers
```
┌──────────────────────────────┐
│  ┌─────────────────┐         │
│  │   CARD          │         │
│  │            ┌────┼───────┐ │
│  └────────────┼────┘       │ │
│               │   IMAGE    │ │
│               └────────────┘ │
└──────────────────────────────┘
```

**The Bleed** — Full-width elements between contained sections
```
│  max-w-6xl content here     │
├─────────────────────────────┤
█████████ FULL BLEED IMAGE █████
├─────────────────────────────┤
│  max-w-6xl content here     │
```

**Bento Grid** — Mixed-size cards in a masonry-like grid
```
┌────────┬────────┬──────────┐
│  TALL  │  SQ    │  WIDE    │
│  CARD  │  CARD  │  CARD    │
│        ├────────┤          │
│        │  SQ    │          │
│        │  CARD  ├──────────┤
├────────┤        │  SQ      │
│  WIDE CARD      │  CARD    │
└─────────────────┴──────────┘
```

## 6. Motion & Animation

### The Rules

1. **One hero animation per page** — a staggered reveal on load. This is your "wow" moment.
2. **Every hover state must animate** — opacity, scale, translate, or color. No instant changes.
3. **Scroll-triggered animations** for below-the-fold content. Elements should fade/slide in as they enter viewport.
4. **Easing matters more than duration**: Use `cubic-bezier(0.16, 1, 0.3, 1)` for smooth deceleration. Never use `linear` or basic `ease`.
5. **Duration**: 200-300ms for micro-interactions. 500-800ms for section reveals. 1000-1500ms for hero animations.

### CSS Animation Toolkit

```css
/* Custom easing curves */
:root {
  --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-out-quint: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-in-out-circ: cubic-bezier(0.85, 0, 0.15, 1);
  --spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* Staggered fade-in on load */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(24px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.stagger-in > * {
  opacity: 0;
  animation: fadeInUp 0.8s var(--ease-out-expo) forwards;
}
.stagger-in > *:nth-child(1) { animation-delay: 0ms; }
.stagger-in > *:nth-child(2) { animation-delay: 80ms; }
.stagger-in > *:nth-child(3) { animation-delay: 160ms; }
.stagger-in > *:nth-child(4) { animation-delay: 240ms; }
.stagger-in > *:nth-child(5) { animation-delay: 320ms; }

/* Scroll-triggered reveal (use IntersectionObserver to add .visible) */
.reveal {
  opacity: 0;
  transform: translateY(32px);
  transition: opacity 0.7s var(--ease-out-expo),
              transform 0.7s var(--ease-out-expo);
}
.reveal.visible {
  opacity: 1;
  transform: translateY(0);
}

/* Smooth hover lift */
.hover-lift {
  transition: transform 0.3s var(--ease-out-expo),
              box-shadow 0.3s var(--ease-out-expo);
}
.hover-lift:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-lg);
}

/* Magnetic button effect (pair with JS) */
.magnetic-btn {
  transition: transform 0.2s var(--ease-out-expo);
}

/* Gradient border animation */
@keyframes borderRotate {
  from { --angle: 0deg; }
  to { --angle: 360deg; }
}
@property --angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}
.animated-border {
  border: 1px solid transparent;
  background: linear-gradient(var(--bg-primary), var(--bg-primary)) padding-box,
              conic-gradient(from var(--angle), var(--accent), transparent, var(--accent)) border-box;
  animation: borderRotate 4s linear infinite;
}
```

### Framer Motion Patterns (for React/Next.js)

```jsx
// Staggered container
const container = {
  hidden: { opacity: 0 },
  show: {
    opacity: 1,
    transition: { staggerChildren: 0.08, delayChildren: 0.1 }
  }
};

const item = {
  hidden: { opacity: 0, y: 24 },
  show: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.6, ease: [0.16, 1, 0.3, 1] }
  }
};

// Usage
<motion.div variants={container} initial="hidden" animate="show">
  <motion.h1 variants={item}>Heading</motion.h1>
  <motion.p variants={item}>Subtext</motion.p>
  <motion.div variants={item}>CTA</motion.div>
</motion.div>

// Scroll-triggered section
<motion.section
  initial={{ opacity: 0, y: 40 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: "-100px" }}
  transition={{ duration: 0.7, ease: [0.16, 1, 0.3, 1] }}
>
  {/* content */}
</motion.section>
```

## 7. Visual Texture & Depth

### Background Techniques

**Noise/Grain Overlay** (adds warmth, removes the "flat digital" look)
```css
.grain::after {
  content: '';
  position: fixed;
  inset: 0;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 256 256' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noise'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.9' numOctaves='4' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noise)' opacity='0.04'/%3E%3C/svg%3E");
  pointer-events: none;
  z-index: 9999;
  opacity: 0.4;
}
```

**Radial Gradient Glow** (adds depth to dark backgrounds)
```css
.glow-bg {
  background:
    radial-gradient(ellipse 60% 40% at 50% 0%, var(--accent-muted) 0%, transparent 70%),
    radial-gradient(ellipse 40% 60% at 80% 100%, rgba(99, 102, 241, 0.08) 0%, transparent 70%),
    var(--bg-primary);
}
```

**Dot Grid Pattern**
```css
.dot-grid {
  background-image: radial-gradient(circle, var(--border) 1px, transparent 1px);
  background-size: 24px 24px;
}
```

**Glassmorphism Card**
```css
.glass-card {
```

## 9. Tech Stack Recommendations

### For Speed & Simplicity: HTML + Tailwind + Alpine.js
Best for: Landing pages, marketing sites, portfolios.
```
- Tailwind CSS v4 (utility-first, highly customizable)
- Alpine.js (lightweight interactivity)
- Google Fonts (via <link>)
- Deployed on Vercel/Netlify/Cloudflare Pages
```

### For Full Applications: Next.js + Tailwind + Framer Motion
Best for: SaaS products, dashboards, complex sites.
```
- Next.js 14+ (App Router)
- Tailwind CSS v4
- Framer Motion (animation)
- Shadcn/ui as a BASE (then customize heavily — never ship default shadcn)
- Lucide icons
- next/font for font loading
```

### For Performance-First: Astro + Tailwind
Best for: Content sites, blogs, documentation, sites where speed matters.
```
- Astro 4+
- Tailwind CSS v4
- View Transitions API
- Island architecture for interactive components
```

### For Interactive Experiences: React + Three.js/R3F + GSAP
Best for: Creative portfolios, product showcases, immersive experiences.
```
- React + Vite
- React Three Fiber (3D)
- GSAP + ScrollTrigger
- Lenis (smooth scroll)
```

## 10. Anti-Patterns (The "AI Slop" Blacklist)

These are BANNED. If you catch yourself doing any of these, stop and redesign.

| ❌ AI Slop Pattern | ✅ Do This Instead |
|---|---|
| Purple/blue gradient on white background | Commit to a unique palette from Section 4 |
| Inter / Roboto / Arial everywhere | Use distinctive font pairings from Section 3 |
| Perfectly symmetrical 3-column feature grid | Bento grid, offset layout, or asymmetric composition |
| Generic hero: centered H1 + subtext + 2 buttons | Left-aligned hero with visual element, or split hero |
| `border-radius: 9999px` on everything | Mix border radii: sharp (2-4px) + rounded (12-16px) |
| Blue CTA buttons (#3B82F6) | Use your accent color, make it bold |
| Stock photo of people smiling at laptops | Geometric art, gradients, 3D renders, or real photography |
| Cards with identical padding and no hierarchy | Vary card sizes, add visual hierarchy with type scale |
| `box-shadow: 0 4px 6px rgba(0,0,0,0.1)` | Use layered shadows or glow effects from your accent |
| Linear animations / `ease` timing | Custom cubic-bezier curves from Section 6 |
| Rainbow gradient text (overused) | Single accent color text or subtle 2-color gradient |
| Testimonials in round-avatar carousels | Editorial-style quote blocks with personality |
| Hamburger menu that slides from right | Fullscreen overlay with staggered text animation |
| Footer with 4 equal columns of links | Asymmetric footer with personality, big CTA |
| "Get Started" / "Learn More" on every button | Specific, action-oriented copy: "Deploy Now", "See It Live" |

## 11. Page-Type Playbooks

### Landing Page / Marketing Site

```
STRUCTURE:
1. Nav (sticky, glass effect)
2. Hero (90-100vh, staggered animation, ONE clear CTA)
3. Social proof bar (logos, minimal)
4. Problem → Solution (before/after or pain-point cards)
5. Features (bento grid or staggered sections)
6. How it works (3-step with connecting line/timeline)
7. Testimonial (1 strong quote, editorial style)
8. Pricing (if applicable — max 3 tiers)
9. Final CTA (full-width, bold, different bg)
10. Footer

KEY RULES:
- Hero must be LEFT-ALIGNED or SPLIT LAYOUT (never centered with 2 buttons)
- Each section has a different visual density
- Maximum 2 CTA styles on the entire page
- Social proof near the top, testimonials near the bottom
- Alternate background colors/textures between sections
```

### Dashboard / SaaS App

```
STRUCTURE:
- Sidebar nav (collapsible, 240px default)
- Top bar (breadcrumb, search, user avatar)
- Main content area with clear hierarchy
- Cards/widgets with consistent sizing

KEY RULES:
- Use a strict 8px grid
- Color-code by data type or status
- Tables: zebra striping or hover rows, never both
- Charts: max 4-5 colors, always with legend
- Loading states: skeleton loaders that match actual content shapes
- Empty states: illustration + clear action
```

### Portfolio / Creative

```
STRUCTURE:
1. Bold name/logo + minimal nav
2. Full-bleed hero (project image or type-driven)
3. Project grid (varied sizes, hover reveals)
4. About section (personality-driven)
5. Contact (simple, direct)

KEY RULES:
- Let the work speak — minimal UI chrome
- Hover effects on project cards MUST be delightful
- Page transitions between projects
- Typography IS the design
- Whitespace is generous
```

## 12. Performance & Accessibility

### Performance Checklist

- [ ] Images: Use `next/image`, WebP/AVIF, proper `sizes` attribute
- [ ] Fonts: `font-display: swap`, subset if possible, preload critical fonts
- [ ] CSS: Purge unused styles (Tailwind does this by default)
- [ ] Animations: Use `transform` and `opacity` only (GPU-accelerated)
- [ ] Lazy load: Below-fold images and heavy components
- [ ] Bundle: Code-split routes, tree-shake dependencies
- [ ] Target: LCP < 2.5s, FID < 100ms, CLS < 0.1

### Accessibility Checklist

- [ ] Color contrast: WCAG AA minimum (4.5:1 body text, 3:1 large text)
- [ ] Focus indicators: Visible, styled (not default blue outline)
- [ ] Keyboard navigation: Tab order makes sense, skip-to-content link
- [ ] Alt text: Every meaningful image has descriptive alt text
- [ ] Heading hierarchy: Single h1, logical h2→h3 nesting
- [ ] Motion: `prefers-reduced-motion` media query disables animations
- [ ] Screen reader: Semantic HTML, ARIA labels where needed

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 13. Pre-Ship Quality Checklist

Before presenting ANY website, verify ALL of the following:

### Visual Quality
- [ ] The design has a clear, intentional aesthetic direction
- [ ] Typography is distinctive (not default system/AI fonts)
- [ ] Color palette is cohesive with proper contrast
- [ ] Spacing rhythm is consistent
- [ ] At least ONE element "breaks the grid" or surprises
- [ ] Background has texture/depth (not flat solid color)
- [ ] No two sections look identical in layout

### Interactivity
- [ ] ALL buttons and links have hover/active states
- [ ] Staggered load animation on hero section
- [ ] Scroll-triggered reveals for below-fold content
- [ ] Smooth transitions (no instant state changes)
- [ ] Custom easing curves (not default `ease`)

### Responsiveness
- [ ] Mobile layout is not just "stacked desktop"
- [ ] Touch targets are 44px+ minimum
- [ ] Font sizes are readable on mobile (16px+ body)
- [ ] No horizontal scroll at any breakpoint
- [ ] Navigation transforms appropriately for mobile

### Code Quality
- [ ] CSS custom properties for all design tokens
- [ ] Semantic HTML elements
- [ ] No inline styles (use classes/utilities)
- [ ] Images optimized and lazy-loaded
- [ ] Clean, readable component structure
