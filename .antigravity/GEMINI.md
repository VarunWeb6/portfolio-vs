# GEMINI.md — Antigravity-Specific Frontend Rules

Read and follow ALL rules in AGENTS.md first. This file adds Antigravity-specific behavior.

## Agent Behavior
- When in **Plan mode**, always output the Design Brief (audience, mood, fonts, palette, signature moment) as a Plan Artifact before generating code.
- Always include a comment block at the top of generated files summarizing the aesthetic.
- Verify the output passes the "Screenshot Test" before completion.

## Definition of Done
1. Code renders flawlessly in the browser.
2. Animated hover/focus states on ALL interactions.
3. Staggered hero reveal transition.
4. No banned fonts (Inter, etc.) used.
5. Textured background (grain/glow/dots).
6. Responsive layout (mobile-first approach).
7. `prefers-reduced-motion` support.
